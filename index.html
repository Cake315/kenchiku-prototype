取り扱い木材・資材一覧

奈良県産「吉野桧」をはじめ、格調高い空間を創る銘木建材の平米単価・グレード・特徴

1. 吉野桧（床用フローリング）

一枚もの無垢床材
吉野桧 一枚もの通常品フローリング
¥9,339 / ㎡ (税込) ［税別：¥8,490/㎡］
グレード：通常品（節あり・埋木処理） 仕上：無塗装

奈良県産の吉野桧を使用した一枚もの無垢フローリング。通常グレードのため、節や抜け節を防ぐための埋め木処理が施されています。針葉樹ならではの柔らかな足触りと、吉野桧の上品な香りが特徴です。

吉野桧 一枚もの上小節フローリング
¥11,550 / ㎡ (税込) ［税別：¥10,500/㎡］
グレード：上小節（直径10〜20mm程度の小節） 仕上：無塗装

直径10mm〜20mm程度の小さな節（上小節）が控えめに入り、通常品よりもすっきりとした落ち着きのある表情。死節には特殊なコマ型埋木処理が施されており、耐久性と美観を両立しています。

吉野桧 一枚もの無節フローリング
¥18,480 / ㎡ (税込) ［税別：¥16,800/㎡］
グレード：最高ランク 無節（節なし） 仕上：無塗装（受注生産品）

表面に節がほとんど入らない最高峰の「無節」グレード。桧特有のきめ細やかな木肌と美しい光沢・木目を存分に味わえる高級仕様です。

2. 吉野桧（壁・天井用 パネリング / 羽目板）

壁・天井内装材
吉野桧 パネリング通常品
¥7,480 / ㎡ (税込) ［税別：¥6,800/㎡］
グレード：通常品（節あり・埋め木あり） 仕上：無塗装（短手サネ加工なし）

壁面や天井の内装材（パネリング／羽目板）として使える吉野桧。桧の爽やかな芳香によるリラクゼーション効果と防虫・調湿効果が期待できます。短手（エンドマッチ）のサネ加工はありません。

吉野桧 パネリング上小節
¥9,900 / ㎡ (税込) ［税別：¥9,000/㎡］
グレード：上小節（小さな節がまばら） 仕上：無塗装

小さな節がまばらに入る上小節グレードのパネリング。節の主張が穏やかで、明るく洗練された和・洋どちらの空間にも自然に馴染みます。

吉野桧 パネリング無節
¥16,500 / ㎡ (税込) ［税別：¥15,000/㎡］
グレード：最上級 無節（節なし） 仕上：無塗装（受注生産品）

表面に節のない最上級無節グレードのパネリング材。壁や天井一面に張ることで、整った柾目・板目と桧の明るい光沢が広がる贅沢な空間づくりが可能です。

3. 吉野桧（床暖房兼用フローリング）

熱源温度60℃まで対応
吉野桧 一枚もの（床暖房兼用）通常品フローリング
¥10,989 / ㎡ (税込) ［税別：¥9,990/㎡］
グレード：通常品（節あり・熱対応埋木処理） 仕上：無塗装

熱源温度60℃までの床暖房に対応した、一枚もの純国産無垢フローリング。床暖房の熱変化で節が痩せて抜け落ちないよう、あらかじめしっかりとした埋木処理が施されています（施工時は熱源と床材の間に5.5mm構造用合板を挟む工法を推奨）。

吉野桧 一枚もの（床暖房兼用）上小節フローリング
¥15,950 / ㎡ (税込) ［税別：¥14,500/㎡］
グレード：上小節（節が小さく目立たない） 仕上：無塗装

床暖房兼用タイプの上小節グレード。節が小さく目立ちにくいため、床暖房の機能性を備えつつ、すっきりと上品な和モダン空間を演出します。

4. 国産桧（四国・九州産等 一枚ものフローリング）

高コストパフォーマンス無垢一枚もの
国産桧 一枚もの通常品フローリング

グレード：通常品（生き生きとした自然な節） 産地：四国・九州産等 ／ 無塗装

主に四国や九州産の桧を使用した、コストパフォーマンスに優れる一枚もの通常グレード。しっかりとした節があり、木本来の素朴で生き生きとした表情を楽しめます。

国産桧 一枚もの上小節フローリング
¥11,880 / ㎡ (税込) ［税別：¥10,800/㎡］
グレード：上小節（小さな節のみを選別） 産地：四国・九州産等 ／ 無塗装

小さな節のみを選別した上小節グレード。通常品よりも節が主張しすぎず、桧らしい明るい清潔感と上品さを手頃なバランスで取り入れることができます。

国産桧 一枚もの無節フローリング
¥14,190 / ㎡ (税込) ［税別：¥12,900/㎡］
グレード：国産桧 最高ランク無節（節なし） 産地：四国・九州産等 ／ 無塗装

国産桧フローリングの最高ランク（無節）。表面に節がなく、通直で緻密な木肌の美しさが際立ちます。高級和室やモダン住宅のリビングなどにおすすめです。
